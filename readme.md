# 🧭 Ieum — AI 웹 길안내 도우미

> "어디로 안내해 드릴까요?" — 복잡한 웹사이트에서 어디를 눌러야 할지, AI가 한 단계씩 짚어드립니다.

디지털이 익숙하지 않은 어르신과 디지털 약자를 위한 크롬 확장 프로그램입니다.
은행·공공기관처럼 메뉴가 복잡한 사이트에서 **"여기 누르세요 → 이제 여기"** 하고 목적지까지 직접 길을 안내합니다.
화면을 바꾸지 않고, 사용자가 실제로 클릭하도록 **강조 + 화살표 + 음성**으로 도와줍니다.

---

## ✨ 핵심 기능

1. **AI 클릭 경로 안내** — 원하는 목적지를 말(또는 입력)하면, AI가 클릭해야 할 버튼을 **순서대로** 짚어줍니다.
2. **단계별 시각 강조** — 눌러야 할 버튼에 파란 글로우 + 👈 화살표 + "STEP 1/3" 안내 툴팁을 띄웁니다.
3. **음성 입력 지원** — 타이핑이 어려운 분을 위해 🎤 한국어 음성으로 목적지를 말할 수 있습니다.
4. **진행 로드맵** — 화면 우측에 전체 클릭 순서를 표시하고, 끝낸 단계는 줄을 그어 보여줍니다.
5. **도착 알림** — 목적지에 도달하면 화면 가운데 큼지막한 **"✓ 도착했습니다!"** 배너로 안내합니다.

---

## 🔍 어떻게 동작하나

```
사용자 입력/음성  →  페이지 DOM 크롤링  →  Gemini 분석  →  클릭 시퀀스  →  단계별 안내
   "공과금 내고 싶어"      (모든 클릭 요소 수집)    (경로 계산)      (순서 반환)      (강조·화살표·도착)
```

1. **DOM 크롤링** — 페이지의 모든 클릭 가능한 요소(링크·버튼·메뉴·숨은 메뉴 등)를 위치·표시 여부와 함께 수집합니다.
2. **AI 분석** — 수집한 구조와 사용자 요청을 Gemini에 보내, 목적지까지의 클릭 순서를 받아옵니다.
3. **단계별 안내** — 각 단계의 버튼을 강조하고, 사용자가 직접 클릭하면 다음 단계로 넘어갑니다.

---

## 💪 기술적 강점

- **동적 UI 대응** — 클릭 후 메뉴가 펼쳐지는 사이트도, 대상 버튼이 나타날 때까지 기다렸다가(폴링) 안내합니다. 숨겨진 메뉴는 그 메뉴를 여는 상위 버튼부터 순서에 포함합니다.
- **페이지 전환 대응** — 클릭으로 다른 페이지로 넘어가도, 진행 상태를 저장해 새 페이지에서 **자동으로 안내를 이어갑니다.**
- **정적·동적 사이트 모두 지원** — 어떤 웹사이트에서든(`<all_urls>`) 동작합니다.
- **접근성 우선** — 큰 글씨 배너, 고대비 강조, 음성 입력으로 디지털 약자 친화적으로 설계했습니다.

---

## 🛠 기술 스택

- **Platform:** Chrome Extension (Manifest V3) — content script + service worker
- **AI:** Google Gemini 2.5 Flash (클릭 경로 분석)
- **Automation:** JavaScript DOM 크롤링 & MutationObserver 기반 동적 추적
- **Input:** Web Speech API (한국어 음성 인식, `ko-KR`)

---

## 🚀 설치 및 사용

1. `chrome://extensions` 접속 → 우측 상단 **개발자 모드** 켜기
2. **"압축해제된 확장 프로그램을 로드합니다"** → 이 폴더 선택
3. 확장 프로그램 **옵션 페이지**에서 Gemini API 키 입력 후 저장
4. 안내받을 웹사이트에서 툴바의 **Ieum 아이콘** 클릭 → 하단 위젯 등장
5. **"어디로 안내해 드릴까요?"** 에 목적지를 입력하거나 🎤로 말하면 안내 시작
